# Extensão do Strava Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** O Léguas conecta à conta do Strava, importa as caminhadas e trilhas, liga cada uma à caminhada manual do mesmo dia quando já existir, e escreve uma linha do jogo na descrição da atividade.

**Architecture:**
- **Módulo `Strava`:**
  - `Strava::Client` faz o HTTP com `Net::HTTP`. O transporte é injetável, pra testar sem rede.
  - `Strava::Connection` guarda os tokens, criptografados, e controla a busca.
  - `Strava::Importer` transforma atividades em `Walk`.
  - `Strava::GameLine` monta a linha do jogo a partir da jornada antes e depois de cada caminhada.
  - `Strava::WriteBackJob` escreve a linha no Strava.
- **Telas:**
  - O OAuth fica em `Strava::ConnectionsController` e `Strava::AuthorizationsController`.
  - A busca automática é um POST para `Strava::SyncsController`, disparado por um controller Stimulus nas telas Fase e Menu.
- **Progresso:** continua calculado de `Walk` por `User::Journey`. Nada de posição é gravado.

**Tech Stack:** Rails 8.1, Ruby 4.0.6, SQLite, Hotwire (importmap, Stimulus em `app/frontend/controllers/`), Tailwind 4, Minitest. Sem gems novas.

**Spec:** `docs/superpowers/specs/2026-10-28-strava-design.md`

## Global Constraints

- Todo comando roda com o prefixo `mise exec ruby@4.0.6 --`. Testes de sistema precisam de `SE_CHROMEDRIVER=/usr/bin/chromedriver`.
- TDD: o teste falha antes do código. Os testes de lógica usam o mundo pequeno de `test/world/` quando dependem de km da trilha. Os testes de controller usam o mundo real, como os existentes.
- Nunca grave posição, XP ou conquista. O progresso vem de `User::Journey`.
- Nenhum teste faz chamada de rede. Tudo passa por um `Strava::Client` com transporte falso, ou por `FakeStravaClient` (Task 2).
- Toda a interface é em pt-BR, e os textos do spec são copiados literalmente.
- Só entram atividades com `sport_type` `"Walk"` ou `"Hike"`.
- Valem as regras de `Walk`: data de hoje ou dos últimos `Backdatable::RETROACTIVE_DAYS` (7) dias, e no máximo `Walk::DAILY_LIMIT_KM` (100) km por dia.
- Prefixo da linha do Léguas no Strava: `🥾 Léguas`.
- Escopos pedidos no OAuth: `activity:read_all,activity:write`.
- `config/master.key` nunca é lido em voz alta, copiado nem enviado. As credenciais do Strava são colocadas pelo autor (Task 8).

## Review Focus

1. **Fuso de `start_date_local`.** `"2026-10-25T07:10:00Z"` é a hora local do atleta, mesmo com o `Z`. A data é a parte `YYYY-MM-DD` da string, nunca `Time.zone.parse(...).to_date`. Teste na Task 3.
2. **Descrição vazia no Strava.** `description: nil` ou `""` vira só a linha do Léguas, sem linha em branco antes. Uma descrição que já tem a linha do Léguas no meio troca só aquela linha. Teste na Task 4.
3. **Token vencido no meio da busca.** O token é renovado antes da chamada. Um refresh recusado (401) apaga a conexão sem exceção pra fora. Teste na Task 3.
4. **Busca dupla.** Duas chamadas de `sync!` seguidas: a segunda não chama o Strava. Teste na Task 3.
5. **Atividade que fura uma regra no meio da lista.** Uma atividade velha ou acima do limite do dia é pulada, e as seguintes ainda entram. Teste na Task 3.

**Interfaces:**
- Produces:
  - `Strava::Error < StandardError` e `Strava::Unauthorized < Strava::Error`, definidos em `app/models/strava.rb`.
  - `Strava::Client.new(transport: Strava::Client::NetTransport.new, client_id: credentials, client_secret: credentials)`. As credenciais padrão vêm de `Rails.application.credentials.dig(:strava, :client_id)` e `:client_secret`. Métodos:
    - `#authorize_url(redirect_uri:, state:) -> String`: `https://www.strava.com/oauth/authorize` com `client_id`, `redirect_uri`, `response_type=code`, `approval_prompt=auto`, `scope=activity:read_all,activity:write` e `state`.
    - `#exchange_code(code) -> Hash`: POST `https://www.strava.com/oauth/token` com `grant_type=authorization_code`. Devolve o JSON (`"access_token"`, `"refresh_token"`, `"expires_at"`, `"athlete" => {"id"}`).
    - `#refresh(refresh_token) -> Hash`: o mesmo endpoint, com `grant_type=refresh_token`.
    - `#deauthorize(access_token) -> void`: POST `https://www.strava.com/oauth/deauthorize`.
    - `#activities(access_token, after:) -> Array<Hash>`: GET `https://www.strava.com/api/v3/athlete/activities?after=<epoch>&per_page=30`.
    - `#activity(access_token, id) -> Hash`: GET `/api/v3/activities/{id}`.
    - `#update_description(access_token, id, description) -> Hash`: PUT `/api/v3/activities/{id}` com `description`.
  - O transporte é um objeto com `#call(method, url, params:, token:) -> [Integer status, String body]`:
    - `method` é `:get`, `:post` ou `:put`;
    - `params` vira query string no GET e form no POST e no PUT;
    - `token` vira o header `Authorization: Bearer`.

    O cliente faz o parse do JSON. Status 401 levanta `Strava::Unauthorized`; qualquer outro status fora de 2xx, ou erro de rede, levanta `Strava::Error`.
  - `Strava::Polyline.trace(encoded) -> Array<[Float, Float]> | nil`:
    - decodifica o polyline do Google (precisão 5);
    - projeta com x = lng × cos(lat média) e y = −lat;
    - simplifica com RDP até caber em `Route::Trace::MAX_POINTS`;
    - normaliza com `Route::Trace.normalize`.

    Devolve nil quando `encoded` está em branco ou dá menos de 2 pontos.
  - `FakeStravaClient` (só para testes):
    - `#activities_list` (Array), `#details` (Hash id → Hash), `#calls` (Array de `[nome, *args]`), `#refresh_error` e `#fetch_error` (exceção a levantar, ou nil);
    - responde a todos os métodos públicos de `Strava::Client` e registra cada chamada em `calls`;
    - `#update_description` guarda a descrição em `details[id]["description"]`.

- [ ] **Step 3: Implemente o importador e o `sync!`**

O importador:
- processa as atividades em ordem crescente de `start_date_local` e depois de `id`;
- antes de salvar, pula as já importadas (`user.walks.exists?(strava_activity_id:)`) e as ignoradas;
- liga cada manual a uma atividade só, guardando um Set dos ids de manuais já ligadas nesta rodada;
- escolhe a manual pela menor `(manual.km - activity_km).abs`, entre as candidatas com `(a - b).abs / [a, b].max <= MATCH_TOLERANCE`;
- salva cada caminhada com `save`. Se a caminhada for inválida (data, limite), pula. Um `RecordNotUnique` também é pulado.

O `sync!`:
